# Excel-Sales-Analysis-Dashboard



## Project Overview

This project is an interactive Sales Analysis Dashboard built using Microsoft Excel. It provides a consolidated view of sales performance, gross profit, orders, units sold, sales channels, regions, and country-wise revenue.

The dashboard helps users monitor key business performance indicators (KPIs) and explore sales trends using interactive slicers and visualizations.

## Dashboard Features

### 1. Monthly Revenue and Profit Analysis

- Tracks monthly revenue and gross profit.
- Helps identify monthly trends and fluctuations.
- Compares revenue performance with profitability.

### 2. Top 5 Countries by Revenue

- Highlights the five leading countries by revenue.
- Helps compare sales performance across countries.

### 3. Revenue Share by Channel

- Compares revenue contributions from Corporate, Marketplace, Online Store, and Retail Partners.
- Displays each channel's share of total revenue.

### 4. Region-Wise Comparison

- Compares revenue contributions across Central Europe, Northern Europe, Southern Europe, and Western Europe.

### 5. Country-Wise Map Chart

- Provides a geographical view of revenue distribution.
- Helps visualize differences in country-level sales performance.

### 6. Interactive Slicers

The dashboard includes filters for:

- Marketplace
- Region
- Product Category
- Month

These filters allow users to explore different segments of the sales data.
